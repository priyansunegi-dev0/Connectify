<p id="description">📡 Connectify is a real-time online conferencing and collaboration platform that allows users to create or join virtual meetings using a unique meeting code. It supports high-quality video/audio conferencing screen sharing and live chat — all accessible via the browser. 🚀 Features 🔗 Create or join online meetings using a unique meeting code 🖥️ Real-time screen sharing for presentations and collaboration 🎙️ Peer-to-peer audio and video communication 💬 Live chat messaging during meetings 🔒 Secure and private meeting rooms 🌐 Built with WebRTC and WebSockets (Socket.io) for fast low-latency communication 🛠️ Tech Stack Frontend: React Backend: Node.js Express Real-time Communication: WebRTC Socket.io Database: MongoDB (for storing user sessions etc.)</p>

<h2>🧐 Features</h2>

Here're some of the project's best features:

*   🔗 Create or join online meetings using a unique meeting code
*   🖥️ Real-time screen sharing for presentations and collaboration
*   🎙️ Peer-to-peer audio and video communication
*   💬 Live chat messaging during meetings
*   🌐 Built with WebRTC and WebSockets (Socket.io) for fast low-latency communication

  
  
<h2>💻 Built with</h2>

Technologies used in the project:

*   React.js – For building the user interface
*   JavaScript (ES6+) – Application logic and interactivity
*   Node.js – Runtime environment
*   Express.js – Web framework for handling routes and APIs
*   WebRTC – For peer-to-peer video audio and screen sharing
*   Socket.io – For real-time bi-directional event-based communication (chat signaling)
*   MongoDB – NoSQL database used to store:User data Meeting metadata Chat history (if persisted) Meeting codes and session info
